
Student Expense Tracker

A simple Python command-line application for tracking student expenses.

1. Project Overview

The Student Expense Tracker is a command-line project developed in Python. It is designed to help students record and manage their expenses through a terminal.

2. Technologies Used

- Python 3
- Command-line interface

3. Requirements

- Python 3 installed on your computer
- A terminal or command prompt

4. Installation and Setup

Step 1: Install Python

Download and install Python 3 from the official website:

https://www.python.org/downloads/

During installation on Windows, enable the option to add Python to PATH if available.

Step 2: Verify Python Installation

Open a terminal and run:

python --version

If that command does not work on Windows, try:

py --version

Step 3: Clone the Repository

Run:

git clone https://github.com/deoaljashan-coder/student-expense-tracker.git
cd student-expense-tracker
python expense_tracker.py

4. How to Run

Open a terminal inside the project folder and execute:

python expense_tracker.py

On Windows, you can also use:

py expense_tracker.py

Follow the instructions displayed by the program to interact with the expense tracker.

5. Project Structure
